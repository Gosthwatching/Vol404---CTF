Zone Flag Verrouillee

Debloquez l'acces avec un token temporaire, puis validez la reponse finale.

Verification phishing

Generez un report phishing en console, puis collez ici le reportId obtenu pour verifier son etat.

fetch('/phish/report', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  credentials: 'include',
  body: JSON.stringify({ url: '/phish/page/<id>' })
}).then(r => r.json()).then(data => {
  console.log(data);
  window._reportId = data.reportId;
});

Si l'etat reste pending, attendez le prochain passage du worker puis recommencez.

Quand le token est recupere, utilisez-le en console pour deverrouiller l'acces :

fetch('/flag/unlock', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  credentials: 'include',
  body: JSON.stringify({ token: window._phishToken })
}).then(r => r.json()).then(console.log);
